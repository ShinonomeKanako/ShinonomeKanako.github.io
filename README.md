# Shinonome's Space

Personal blog hosted at [ShinonomeKanako.github.io](https://ShinonomeKanako.github.io/).

Built with [Astro](https://astro.build/) and the [Fuwari](https://github.com/saicaca/fuwari) blog template.

## Development

```sh
pnpm install
pnpm dev
```

Create a new post with:

```sh
pnpm new-post <filename>
```

Build the production site with:

```sh
pnpm build
```
